# Mac用開発環境設定Playbook

Ansibleを使用してMac用開発環境設定をできるだけ自動化するためのファイル。

## 事前準備

1. Xcode Command Line Toolsをインストール
1. Homebrewをインストール
1. HomebrewからAnsibleをインストール
1. このリポジトリをクローン
1. リポジトリのディレクトリで `make` を実行

## .bash_profileの内容

PATHや使用するPHP、Node.jsなどの設定は各自の環境に合わせて設定。

## 実行環境

macOS Tahoe / Ver.26.6.2

## Ansibleのバージョン

ver2.21.0
